CORPUL MEU - PWA

Aceasta este versiunea web instalabila (PWA).
Datele sunt salvate local in browser prin localStorage.

Pentru testare locala pe Windows:
1. Deschide PowerShell in acest folder.
2. Ruleaza: python -m http.server 8080
3. Deschide http://localhost:8080

Pentru folosire pe iPhone, folderul trebuie publicat pe un site HTTPS.
Apoi deschizi URL-ul in Safari si folosesti Share > Add to Home Screen.

IMPORTANT: exporta periodic CSV din Setari. Stergerea datelor Safari/site-ului poate elimina jurnalul local.
